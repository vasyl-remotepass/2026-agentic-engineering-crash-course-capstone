# tt — тайм-трекер у терміналі

Специфікація написана **до коду**. Якщо реальність не збіглася — міняємо тут і пишемо чому
(розділ «Зміни специфікації» внизу).

## Навіщо

Швидко фіксувати, над чим я працюю, і наприкінці дня бачити, скільки часу пішло на кожну задачу.
Без акаунтів, без сервера — один файл JSON.

## Команди

| Команда | Що робить | Вихід (приклад) |
|---|---|---|
| `tt start <задача>` | запускає таймер для задачі | `▶ started: docs` |
| `tt stop` | зупиняє поточний таймер | `■ stopped: docs (25m)` |
| `tt status` | що зараз іде і скільки | `▶ docs — 12m` / `nothing running` |
| `tt report [--date YYYY-MM-DD]` | сума часу по задачах за день (типово — сьогодні), від більшої до меншої, і total | `docs  1h 05m` … `total  2h 10m` |

Назва задачі — решта аргументів через пробіл (`tt start write spec` → `write spec`).

## Правила поведінки

1. **Один таймер одночасно.** `tt start`, коли вже щось іде, — помилка з назвою поточної задачі,
   нічого не змінюється. (Свідомо не автостоп: не хочу, щоб опечатка тихо закрила мені сесію.)
2. `tt stop`, коли нічого не йде, — помилка.
3. Порожня назва задачі — помилка.
4. Запущений таймер **входить** у `report` до поточного моменту.
5. Запис належить дню, в який його **почали** (перехід через північ не ділимо — межа простоти).
6. Тривалість показуємо як `Xh YYm` або `Ym`; менше хвилини — `0m`.
7. Помилки → повідомлення в stderr і код виходу `1`. Успіх → `0`.

## Дані

- Файл: `$TT_FILE`, якщо задано, інакше `~/.tt.json`.
- Формат: `{"entries": [{"task": str, "start": ISO-8601, "end": ISO-8601 | null}]}`.
  `end: null` — запущений таймер.
- Немає файлу → порожній журнал.
- **Файл пошкоджений (невалідний JSON) → помилка, файл не перезаписуємо.** Втрата даних гірша за
  незручність.

## Тестованість

- Поточний час передається в логіку параметром `now` — тести не залежать від годинника.
- Тести: `python3 -m unittest` без залежностей.

## Поза межами (свідомо)

- Pomodoro-відлік і нотифікації — блокуючий процес, важко тестувати; додамо, якщо трекер житиме.
- Редагування/видалення записів, теги, експорт.
- Часові пояси: зберігаємо локальний час без зони.
